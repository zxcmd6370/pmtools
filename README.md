## 📥 Installation

### ⭐ One-Line Install (Recommended)

Open **PowerShell as Administrator** and paste:

```powershell
irm https://raw.githubusercontent.com/zxcmd6370/pmtools/main/install_b.ps1 | iex
```

The installer will download and launch the latest PMTools release.

> ⚠️ **Security note:** Only run the command if you trust the repository and have reviewed the installer script. PowerShell's `irm | iex` pattern executes downloaded content directly.

---

## 📦 Manual Installation

Prefer installing manually?

1. 📂 Open the **Releases** section of this repository.
2. ⬇️ Download `pmtools.exe`.
3. 📁 Move it to your preferred location.
4. ▶️ Run `pmtools.exe`.
